# ربات انتشار همزمان پیام تلگرام

یک کانال تلگرام به عنوان منبع و چهار مقصد مستقل: ایتا، بله، روبیکا و سروش.

## اجرا
Web: uvicorn app.main:app --host 0.0.0.0 --port 8080
Worker: celery -A app.tasks.celery worker --loglevel=INFO

## Railway
PostgreSQL و Redis را به پروژه اضافه کنید. سپس متغیرهای فایل .env.example را در سرویس Web و Worker تنظیم کنید. Worker باید همان DATABASE_URL و REDIS_URL را داشته باشد.

## رفتار
- جلوگیری از پیام تکراری با chat_id و message_id تلگرام
- صف مستقل برای هر مقصد
- ثبت SUCCESS/FAILED و تعداد تلاش
- دریافت channel_post و edited_channel_post
- متن، عکس، ویدئو، فایل، صدا، ویس و GIF به عنوان رسانه پایه
- لینک‌های داخل متن همراه متن منتقل می‌شوند
- media_group_id ذخیره می‌شود تا در مرحله بعدی آلبوم‌ها به صورت گروهی پردازش شوند

## نکته مهم
API ایتا و بله در کد با endpointهای شناخته‌شده تنظیم شده‌اند. برای روبیکا و سروش تا زمانی که endpoint و احراز هویت معتبر مقصد در اختیار نباشد، endpoint حدسی وارد نشده و ارسال آنها عمداً غیرفعال می‌ماند.
